# goat_yt_player_flutter

A customized YouTube Player for Flutter apps using WebView.

## Features

* Embedded YouTube Player using WebView.
* Custom controller for playing and pausing video.

## Getting started

Add the dependency to your `pubspec.yaml`:

```yaml
dependencies:
  goat_yt_player_flutter: ^0.0.1
```

## Usage

```dart
import 'package:goat_yt_player_flutter/goat_yt_player_flutter.dart';

// ...

GoatYtPlayer(
  controller: GoatYtPlayerController(
    initialVideoId: 'iLnmTe5Q2Qw',
  ),
)
```
